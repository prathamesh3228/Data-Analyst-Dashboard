# Healthcare-Report-Dashboard (Interactive Healthcare Analytics Dashboard in Microsoft Excel)

##  Project Objective
The objective of this project is to develop an interactive Healthcare Data Analysis Dashboard in Microsoft Excel that transforms raw healthcare data into meaningful insights. The dashboard helps analyze patient admissions, hospital performance, treatment costs, length of stay, insurance coverage, and other key healthcare metrics using Pivot Tables, Charts, Slicers, and KPI Cards, enabling data-driven decision-making.

## Process
Understand the Business Problem – Identified the business requirements and KPIs.
Collect the Dataset – Downloaded the healthcare dataset from Kaggle.
Clean the Data – Removed duplicates, handled missing values, and corrected data types.
Prepare the Data – Created helper columns like Age Group and Length of Stay.
Create Pivot Tables – Summarized data for KPIs and different analyses.
Build Charts – Created bar charts, pie charts, line charts, and KPI cards.
Add Interactivity – Used slicers to filter data dynamically.
Design the Dashboard – Arranged KPIs and charts into a clean, user-friendly dashboard for business insights.

Business Understanding → Data Collection → Data Cleaning → Data Preparation → Pivot Tables → Charts → Slicers → Dashboard Design & Insights
