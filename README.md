# Healthcare-Report-Dashboard (Interactive Healthcare Analytics Dashboard in Microsoft Excel)

##  Project Objective
The objective of this project is to develop an interactive Healthcare Data Analysis Dashboard in Microsoft Excel that transforms raw healthcare data into meaningful insights. The dashboard helps analyze patient admissions, hospital performance, treatment costs, length of stay, insurance coverage, and other key healthcare metrics using Pivot Tables, Charts, Slicers, and KPI Cards, enabling data-driven decision-making.
